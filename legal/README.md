# Права и разрешения

Действующие условия размещены в единственном экземпляре в корне: [LICENSE](../LICENSE), [Fan Content Policy](../FAN_CONTENT_POLICY.md), [Contributor Terms](../CONTRIBUTOR_TERMS.md).

Этот раздел содержит [русскую юридическую памятку](LEGAL_NOTES_RU.md), [реестр сторонних ресурсов](THIRD_PARTY_ASSETS.csv) и жизненный цикл будущих редакций:

- [drafts](drafts/README.md) — обсуждаемые изменения и вопросы соглашения соавторов.
- [canon](canon/README.md) — записи принятых решений/указатели на действующие редакции, когда есть реальное подтверждение.
- [archive](archive/README.md) — заменённые условия с причиной и датой.

Не копируйте действующую лицензию в несколько мест. При замене сохраняйте прошлую редакцию с версией и пределами действия; новое условие не расширяет ранее полученное согласие автоматически. Папки здесь публичны: договоры с подписями, адреса и платёжные сведения хранятся отдельно.
