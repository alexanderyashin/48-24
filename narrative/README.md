# Истории

Логлайны, персонажи, сюжетные линии и тексты произведений.

| Область | Содержание |
| --- | --- |
| [Замысел и логлайн](premise/README.md) | Логлайны, премиса, синопсисы, темы и обещание произведения аудитории. |
| [Персонажи](characters/README.md) | Биографии, цели, ограничения, отношения, знания и развитие персонажей. |
| [Сюжетные линии](story-arcs/README.md) | Длинные арки, конфликты, повороты и причинные связи между событиями. |
| [Выпуски и главы](episodes/README.md) | Истории как отдельные выпуски, главы, миссии или приключения. |
| [Сцены](scenes/README.md) | Конкретные сцены, действия, выборы, последствия и постановочные варианты. |
| [Диалоги и голоса](dialogue/README.md) | Диалоги, монологи, словарь персонажей, стиль речи и языковые версии. |

В каждой области есть `drafts`, `canon` и `archive`. Ветки Git — способ параллельной работы; папки статуса — зрелость материала. Слияние в `main` само по себе не делает материал каноном.

Читайте [рабочий процесс](../studio/WORKFLOW.md) и [правила канона](../studio/CANON_POLICY.md). [Главная](../README.md).
