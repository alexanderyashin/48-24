# Истории: контекст для помощника / Narrative assistant context

## Русский

Область: `narrative/` и вложенные папки. Это дополнение к [корневому AGENTS.md](../AGENTS.md); его требования и действующие политики сохраняются. Прочитайте [README](README.md), README целевой папки и [руководство по сюжетам](../studio/guides/writing.md).

- Разрозненная идея начинается во [входящих](../studio/inbox/README.md). Длинная линия — `story-arcs/drafts`; самостоятельная история, глава или миссия — `episodes/drafts`; конкретная сцена — `scenes/drafts`; персонаж — `characters/drafts`; речь — `dialogue/drafts`; общий замысел — `premise/drafts`.
- Используйте соответствующий [шаблон](../templates/README.md). Найдите существующие ARC/CHAR/EP и связи до выдачи нового ID; продолжение существующей карточки не требует создания дубликата.
- Прочитайте связанные факты мира, знания персонажей, время и место действия, открытые DIV/GAP. Отличайте намерение автора, убеждение героя и факт мира. Не достраивайте спорный канон ради гладкого сюжета.
- Сохраняйте авторство идеи, источник и использование ИИ. При нескольких вариантах связывайте их явно; не стирайте версию соавтора. Решение обоих авторов оформляется по [CANON_POLICY](../studio/CANON_POLICY.md).
- Сценарная адаптация конкретного медиа связывается с `products/`; общие персонажи и события не копируются туда как новая истина.

## English

Scope: `narrative/` and descendants. This supplements the [root AGENTS.md](../AGENTS.md); its requirements and authoritative policies still apply. Read this area's [README](README.md), the target README and the [writing guide](../studio/guides/writing.md).

- Capture loose ideas in the [inbox](../studio/inbox/README.md). Route long arcs to `story-arcs/drafts`, standalone stories/chapters/missions to `episodes/drafts`, scenes to `scenes/drafts`, characters to `characters/drafts`, speech to `dialogue/drafts`, and premises to `premise/drafts`.
- Use the appropriate [template](../templates/README.md). Find existing ARC/CHAR/EP records before assigning IDs; continue an existing record without duplicating it.
- Read relevant world facts, character knowledge, time/place and unresolved DIV/GAP entries. Distinguish authorial intent, a character's belief and world fact; preserve unresolved canon.
- Retain attribution, sources and AI provenance. Link alternatives without erasing another author's version. Follow [CANON_POLICY](../studio/CANON_POLICY.md) for both authors' decisions.
- Link media-specific adaptations in `products/` to shared characters and events.
