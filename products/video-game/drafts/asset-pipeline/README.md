# Конвейер игровых ресурсов / Asset pipeline

## Русский

Маршрут OBJ/ART/PHYS → JSON → геометрия/материалы → экспорт → импорт; версии, воспроизводимость и журналы.

Это рабочая область технической реализации, а не утверждённое решение о выборе движка или стека. Здесь размещаются проекты, конфигурации, спецификации, ссылки на внешние open-source компоненты, результаты экспериментов и исходный код по мере появления. Указывайте версию, происхождение, лицензию, зависимости, ограничения и критерии приёмки. Ссылайтесь на [контракт игровых данных](../../../../studio/ENGINE_DATA_CONTRACT.md) и [готовность к 3D](../../../../studio/3D_READINESS_GATES.md), если применимо. Крупные бинарные ресурсы храните по правилам проекта.

## English

OBJ/ART/PHYS → JSON → geometry/materials → export → import; versioning, reproducibility and logs.

This is a working implementation area, not an approved engine or technology choice. Store projects, configuration, specifications, links to open-source components, experiment results and source code as needed. Record versions, provenance, licenses, dependencies, limitations and acceptance criteria. Reference the [engine data contract](../../../../studio/ENGINE_DATA_CONTRACT.md) and [3D readiness gates](../../../../studio/3D_READINESS_GATES.md) where applicable. Follow the project's binary asset rules.
