# Продукты и адаптации

Конкретные реализации общего мира в разных медиа.

| Область | Содержание |
| --- | --- |
| [Компьютерная игра](video-game/README.md) | GDD, механики, системы, квесты, прототипы и связь игры с общим каноном. |
| [Видео и YouTube](youtube/README.md) | Концепции выпусков, сценарии, сториборды, монтаж, озвучка, субтитры и обложки. |
| [Настольная игра](tabletop/README.md) | Правила, баланс, карточки, компоненты, макеты и результаты плейтестов. |
| [Книги](books/README.md) | План томов, рукопись, редактура, корректура, вёрстка, иллюстрации и переводы. |

В каждой области есть `drafts`, `canon` и `archive`. Ветки Git — способ параллельной работы; папки статуса — зрелость материала. Слияние в `main` само по себе не делает материал каноном.

Читайте [рабочий процесс](../studio/WORKFLOW.md) и [правила канона](../studio/CANON_POLICY.md). [Главная](../README.md).
