# Визуал: контекст для помощника / Art assistant context

## Русский

Область: `art/` и вложенные папки. Это дополнение к [корневому AGENTS.md](../AGENTS.md); его требования и действующие политики сохраняются. Прочитайте [README](README.md), README целевой папки и [руководство по ресурсам](../studio/guides/assets-and-products.md).

- Выберите профильную область: персонажи и костюмы, окружение, предметы, символика, карты, интерфейс, палитры, типографика или общий концепт. Новые варианты находятся в её `drafts`.
- Для объекта различайте исторический REF, вымышленный OBJ и реализацию ART по [OBJECT_STANDARD](../studio/OBJECT_STANDARD.md). Сначала найдите связанные карточки и художественные ограничения; не изобретайте их молча по изображению.
- Для изображений и объектов прочитайте [VISUAL_GOVERNANCE](../studio/VISUAL_GOVERNANCE.md); для 3D — [гейты L0–L3](../studio/3D_READINESS_GATES.md), для симуляции — [PHYSICS_GOVERNANCE](../studio/PHYSICS_GOVERNANCE.md). Готовность производства не подтверждает канон.
- Используйте [арт-бриф](../templates/art-brief.md), [ART](../templates/game-art-asset.md), [палитру](../templates/palette.md) или [гарнитуру](../templates/font.md). Каждый бинарный ресурс получает паспорт по [ASSET_WORKFLOW](../studio/ASSET_WORKFLOW.md); внешний референс и лицензия шрифта проверяются отдельно.
- Версии, источники, использованные модели и человеческие правки фиксируются без вымышленных сведений. Публичная папка не разрешает копирование чужого ресурса.

## English

Scope: `art/` and descendants. This supplements the [root AGENTS.md](../AGENTS.md); its requirements and authoritative policies still apply. Read this area's [README](README.md), the target README and the [asset guide](../studio/guides/assets-and-products.md).

- Choose the relevant art area and place new variants in its `drafts`.
- Separate historical REF, fictional OBJ and ART realization under [OBJECT_STANDARD](../studio/OBJECT_STANDARD.md). Find related records and design constraints before interpreting an image.
- Read [VISUAL_GOVERNANCE](../studio/VISUAL_GOVERNANCE.md); add [L0–L3 gates](../studio/3D_READINESS_GATES.md) for 3D and [physics governance](../studio/PHYSICS_GOVERNANCE.md) for simulation. Production readiness does not establish canon.
- Use the linked art-brief, ART, palette or font template. Every binary needs the sidecar required by [ASSET_WORKFLOW](../studio/ASSET_WORKFLOW.md); check reference and font permissions separately.
- Record versions, sources, known models and human edits accurately. Public storage does not grant permission to copy third-party assets.
