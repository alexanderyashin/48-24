# Палитра для первых проб

Пробная система цветов для сравнения изображений, **не утверждённая палитра**. Цветовое пространство: sRGB. HEX задаёт стартовое цветовое отношение, а не обязательный цвет физического источника света.

| Роль | HEX | Применение |
| --- | --- | --- |
| Уголь | `#181B1C` | Глубокие тени, тяжёлые силуэты |
| Холодная сталь | `#53636B` | Наружный металл в холодной среде |
| Мокрый камень | `#6B7272` | Улица и вторичные поверхности |
| Грязный снег | `#BBC0B7` | Холодный свет и снег без стерильной белизны |
| Старая латунь | `#8F7141` | Приборы и богатые детали в малых количествах |
| Тёплый интерьер | `#C18D4D` | Тёплые освещённые поверхности |
| Тёмное дерево | `#4A3029` | Мебель и тяжёлые интерьерные массы |
| Бумага | `#D5C4A1` | Документы и читаемые таблички |

Для пробы сделайте одну и ту же сцену с разными соотношениями холодного и тёплого. Не закрепляйте отдельный цвет за электричеством или газом без постановочной причины. Проверьте различимость персонажа и среды. Печатные профили и контраст UI этой пробой не утверждаются.
