# Palette for initial experiments

[Русский](palette-experiments-v0-1.md) · [Wiki](../../../studio/navigation/en/README.md)

**Draft.** Normative specification for development. Status labels apply to individual source propositions; source consensus is not new canon approval. Translation awaits coauthor review.

[Source: SPOT 0.1](../../../world/world-bible/drafts/spot-0-1-import.md) · Source status labels: EDITORIAL PROPOSAL.

An experimental colour system for comparing images, **not an approved palette**. Colour space: sRGB. HEX values establish a starting colour relationship, not a mandatory physical colour of the light source.

| Role | HEX | Application |
| --- | --- | --- |
| Coal | `#181B1C` | Deep shadows and heavy silhouettes |
| Cold steel | `#53636B` | Exterior metal in a cold environment |
| Wet stone | `#6B7272` | Street and secondary surfaces |
| Dirty snow | `#BBC0B7` | Cold light and snow without sterile whiteness |
| Old brass | `#8F7141` | Instruments and wealthy details in small amounts |
| Warm interior | `#C18D4D` | Warm illuminated surfaces |
| Dark wood | `#4A3029` | Furniture and heavy interior masses |
| Paper | `#D5C4A1` | Documents and legible signs |

For the experiment, create the same scene with different cold-to-warm ratios. Do not assign a separate colour to electricity or gas without a staging reason. Check the distinction between character and environment. This experiment does not approve print profiles or UI contrast.
