# Художественное направление

Визуальные принципы, стиль, композиция, свет, материалы и правила качества.

Здесь должны находиться: гайд стиля, экспериментальные направления, критерии приёмки и технические брифы.

| Папка | Назначение |
| --- | --- |
| [drafts](drafts/README.md) | Черновики, варианты и материалы на рассмотрении |
| [canon](canon/README.md) | Явно утверждённые материалы и версии |
| [archive](archive/README.md) | Отвергнутые и заменённые материалы с причиной |

Текстовые карточки оформляются по [шаблонам](../../templates/README.md). У бинарного файла рядом должен быть паспорт `имя.расширение.asset.json`; крупные исходники подключаются ссылкой согласно [правилам ресурсов](../../studio/ASSET_WORKFLOW.md).

Не делайте копии общей библии мира для отдельного продукта. Используйте ID и ссылку на исходную карточку. [Рабочий процесс](../../studio/WORKFLOW.md) · [Главная](../../README.md).
