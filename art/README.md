# Визуальный язык

Художественные решения, изображения, палитры, шрифты и дизайн.

| Область | Содержание |
| --- | --- |
| [Художественное направление](art-direction/README.md) | Визуальные принципы, стиль, композиция, свет, материалы и правила качества. |
| [Концепт-арт](concept-art/README.md) | Исследовательские изображения и варианты общих художественных решений. |
| [Дизайн персонажей](character-design/README.md) | Внешность, силуэт, костюм, лица, позы и изменения облика персонажей. |
| [Окружение](environments/README.md) | Архитектура, интерьеры, городская среда, ландшафты, погода и освещение. |
| [Предметы и техника](props/README.md) | Оружие, машины, инструменты, транспорт, бытовые предметы и реквизит. |
| [Символика](symbols/README.md) | Эмблемы, гербы, логотипы, знаки, знамена и визуальная идентичность. |
| [Палитры](palettes/README.md) | Цветовые системы мира, эпох, фракций, локаций и отдельных продуктов. |
| [Шрифты и надписи](typography/README.md) | Шрифтовые решения, дореформенные знаки, орфография, вёрстка и надписи в среде. |
| [Карты](maps/README.md) | Географические, городские, тактические и сюжетные карты. |
| [Интерфейсы](interface/README.md) | Визуальные решения UI, HUD, титров, субтитров, карточек и информационных панелей. |

В каждой области есть `drafts`, `canon` и `archive`. Ветки Git — способ параллельной работы; папки статуса — зрелость материала. Слияние в `main` само по себе не делает материал каноном.

Читайте [рабочий процесс](../studio/WORKFLOW.md) и [правила канона](../studio/CANON_POLICY.md). [Главная](../README.md).
