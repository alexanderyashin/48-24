# Производство

Планы, выпускные пакеты, продвижение и междисциплинарные задачи.

| Область | Содержание |
| --- | --- |
| [Планирование](planning/README.md) | Этапы, задачи, зависимости, оценки, риски и очередность производства. |
| [Выпуски](releases/README.md) | Манифесты выпусков, состав, версии, кредиты и проверки готовности. |
| [Представление проекта](marketing/README.md) | Публичные описания, пресс-материалы, анонсы, планы коммуникации и материалы магазина. |

В каждой области есть `drafts`, `canon` и `archive`. Ветки Git — способ параллельной работы; папки статуса — зрелость материала. Слияние в `main` само по себе не делает материал каноном.

Читайте [рабочий процесс](../studio/WORKFLOW.md) и [правила канона](../studio/CANON_POLICY.md). [Главная](../README.md).
