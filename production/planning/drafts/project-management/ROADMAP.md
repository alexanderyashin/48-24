# Дорожная карта / Roadmap

## Русский

Порядок ориентировочный; сроки и исполнители **не назначены**. Это не обещание готовности к конкретной дате.

| Шаг | Результат | Зависимости | Состояние |
| --- | --- | --- | --- |
| R1 | Каталоги, карточки, governance и контракт данных | — | documentation-created |
| R2 | Исследование существующих open-source инструментов и лицензий | R1 | not-started |
| R3 | Решение о целевом движке, версии и формате обмена | R2 | not-started |
| R4 | Минимальный OBJ/ART/PHYS для тестового ящика и реальные 3D-ресурсы | R3 | not-started |
| R5 | Сборка ассета и импорт в тестовую сцену без ручной настройки | R4 | not-started |
| R6 | Тесты падения, коллизий, повреждений, визуальных состояний и разрушения | R5 | not-started |
| R7 | Результаты, несовместимости, доработка контракта и решение о масштабировании | R6 | not-started |

**Критерий:** не объявлять R5/R6 завершёнными по наличию одной JSON-карточки или красивого изображения. / A JSON record or attractive render alone cannot complete R5/R6.

## English

Sequence is provisional; no dates or assignees are invented. First assess open-source components and licensing, then select an engine/version, assemble a test object, import it reproducibly, test behavior and record gaps before scaling.
