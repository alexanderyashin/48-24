# Первые этапы работы студии

Это предложенная очередность, без выдуманных сроков и назначения Ивана на задачи без его согласия.

| Этап | Результат | Зависимость | Кто принимает |
| --- | --- | --- | --- |
| Организация | Структура, права, README, правила ИИ и проверка | Текущий rollout | Саша как инициатор настройки |
| Совместный доступ | Подтверждённый GitHub Ивана и защита main | Логин и настройка доступа | Владельцы доступов |
| Разбор исходника | Проверенные карточки и сохранённые развилки | SPOT и реестры | Оба автора |
| Минимум канона | Небольшой согласованный набор для первой истории | Решение авторов по нужным CAN/DIV/GAP | Оба автора |
| Визуальные пробы | Сопоставимые арты трёх сред, первые палитры и шрифтовые кандидаты | Бриф, права на входы | Оба автора |
| Первый фрагмент | Одна законченная история/эпизод/прототип | Выбор формата и объёма | Оба автора |
| Первый выпуск | Проверенный пакет с правами и кредитами | Приёмка и решение о публикации | Уполномоченные авторы |

## Первые самостоятельные задачи

1. Каждый автор выбирает один не конфликтующий файл/блок. Например, один — локацию, второй — сцену с заданными ограничениями. Назначение не делается автоматически.
2. По DIV011 решить связь сквозного героя и ансамбля; не навязывать это всем сюжетам до решения.
3. Из 60 GAP и 22 DIV выбрать только блокирующие первую историю. Остальные остаются видимыми.
4. Для визуала определить 6–10 пробных сюжетов и критерий сравнения. Арты в этом rollout не генерируются.
5. Проверить один полный цикл draft → review → canon/ archive на небольшой карточке.

Риски старта: слишком широкий первый продукт; неподтверждённые права; потеря статусов источника; параллельная правка одного бинарного мастера. Для каждого из них уже предусмотрен процесс, а конкретные решения остаются за авторами.
