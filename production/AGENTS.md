# Производство: контекст для помощника / Production assistant context

## Русский

Область: `production/` и вложенные папки. Это дополнение к [корневому AGENTS.md](../AGENTS.md); его требования и действующие политики сохраняются. Прочитайте [README](README.md), README целевой области, [WORKFLOW](../studio/WORKFLOW.md) и [RELEASE_PROCESS](../studio/RELEASE_PROCESS.md) для выпусков.

- Планы, зависимости и журналы — `planning/drafts`; состав и проверки выпуска — `releases/drafts`; описания и анонсы — `marketing/drafts`.
- Сначала проверьте [управление проектом](planning/drafts/project-management/README.md), активные Issue/PR и [рабочий реестр](../studio/registers/work-register.csv). Issue/PR остаётся оперативным источником задач, CSV предназначен для задач без Issue.
- Различайте план, фактически выполненную работу, исходную гипотезу и принятое решение. Не обещайте сроки, бюджеты, готовность или согласие другого человека без основания.
- Любой рабочий Markdown внутри `drafts`, включая журналы и планы, получает метаданные по [NAMING_AND_METADATA](../studio/NAMING_AND_METADATA.md). README объясняет папку и не заменяет карточку работы.
- Для выпуска используйте [шаблон адаптации](../templates/adaptation.md), точные версии ресурсов и проверку прав. Подготовка файла анонса не означает разрешение его отправить или опубликовать.

## English

Scope: `production/` and descendants. This supplements the [root AGENTS.md](../AGENTS.md); its requirements and authoritative policies still apply. Read this area's [README](README.md), the target README, [WORKFLOW](../studio/WORKFLOW.md) and [RELEASE_PROCESS](../studio/RELEASE_PROCESS.md) for releases.

- Route plans, dependencies and logs to `planning/drafts`, release manifests/checks to `releases/drafts`, and public descriptions/announcements to `marketing/drafts`.
- Check [project management](planning/drafts/project-management/README.md), active Issue/PR records and the [work register](../studio/registers/work-register.csv). Issue/PR is the operational tracker; CSV covers tasks without an Issue.
- Separate plans, observed completion, assumptions and accepted decisions. Do not invent dates, budgets, readiness or another person's consent.
- All working Markdown inside `drafts`, including logs and plans, needs metadata under [NAMING_AND_METADATA](../studio/NAMING_AND_METADATA.md). A README explains a folder.
- Releases use the [adaptation template](../templates/adaptation.md), exact asset versions and rights checks. Drafting an announcement does not authorize sending or publication.
