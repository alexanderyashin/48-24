# Исследования

Исторические, визуальные и технические основания; факты отделены от авторских решений.

| Область | Содержание |
| --- | --- |
| [История](history/README.md) | Исторические источники и проверки фактов, относящихся к реальной исходной эпохе. |
| [Визуальные референсы](visual-references/README.md) | Ссылки на архитектуру, одежду, материалы, типографику и работы для анализа. |
| [Технические исследования](technical-feasibility/README.md) | Проверки правдоподобия механизмов и производственной выполнимости продуктов. |

В каждой области есть `drafts`, `canon` и `archive`. Ветки Git — способ параллельной работы; папки статуса — зрелость материала. Слияние в `main` само по себе не делает материал каноном.

Читайте [рабочий процесс](../studio/WORKFLOW.md) и [правила канона](../studio/CANON_POLICY.md). [Главная](../README.md).
