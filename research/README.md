# Исследования

Исторические, визуальные и технические основания; факты отделены от авторских решений.

| Область | Содержание |
| --- | --- |
| [История](history/README.md) | Исторические источники и проверки фактов, относящихся к реальной исходной эпохе. |
| [Визуальные референсы](visual-references/README.md) | Ссылки на архитектуру, одежду, материалы, типографику и работы для анализа. |
