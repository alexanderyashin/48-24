# Приёмка исторического материала / Historical intake checklist

- [ ] **RU:** Дата материала и исторический диапазон определены. / **EN:** Creation date and historical scope identified.
- [ ] Тип: первоисточник, вторичная работа, интерпретация либо реконструкция. / Type: primary, secondary, interpretation, or reconstruction.
- [ ] Указаны автор/издатель, коллекция, инвентарный номер (если есть), постоянная ссылка и дата доступа. / Creator/publisher, collection, shelfmark where available, stable URL, and access date recorded.
- [ ] Показана конкретная страница/кадр, относящаяся к утверждению. / Exact page/frame supporting a claim identified.
- [ ] Оригинал, транскрипция, перевод и интерпретация не смешаны. / Original, transcription, translation, and interpretation separated.
- [ ] Исторические названия и современные географические эквиваленты различены. / Historical names distinguished from modern geographical equivalents.
- [ ] Правовой статус проверен, для бинарных файлов есть точный SHA-256 и `.asset.json`. / Rights checked; binary assets have exact SHA-256 and `.asset.json`.
- [ ] ID уникален; главная рубрика одна; дополнительные рубрики — ссылки и теги. / ID unique; one primary topic; related topics use links and tags.
- [ ] Оспариваемые факты, пробелы и допущения отмечены. / Contested claims, gaps, and assumptions noted.
- [ ] Художественные выводы не объявлены каноном. / Creative interpretations not marked as canon.
