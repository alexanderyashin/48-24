# Реестр и правила источников / Source catalog and rules

Библиотека пока содержит **структуру**, а не заполненный корпус исторических материалов. / This library currently contains a **structure**, not an assembled historical corpus.

## Начало работы / Getting started
1. Определите основную предметную рубрику. / Choose one primary thematic topic.
2. Создайте карточку по [шаблону](source-card-template.md) и присвойте уникальный ID `HBS-000001` и далее (проверяйте реестр перед выдачей ID). / Create a [source card](source-card-template.md) with a unique ID; check the register first.
3. Зарегистрируйте запись в [sources.csv](sources.csv). / Register it in [sources.csv](sources.csv).
4. Заполните дату, географию, предметные теги, тип источника и качество свидетельства. / Record dates, geography, tags, type, and evidence quality.
5. Проверьте [лицензию и происхождение](rights-and-provenance.md) перед коммитом бинарного материала. / Check [rights and provenance](rights-and-provenance.md) before adding binary assets.
6. Сохраните ссылки на смежные темы по ID; не размножайте исходники. / Cross-reference by IDs; avoid duplicated copies.
