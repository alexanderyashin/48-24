# Исторические коллекции референсов / Historical Reference Collections

## Русский

Каталог **ссылок на первичные источники**, а не собрание скопированных музейных изображений. Охват: Российская империя и сопредельные регионы, ориентир 1880–1940 годы. Реальные источники показывают историю, а не автоматически канон альтернативного 1941 года.

### Правила каталогизации

Для каждого **выбранного предмета**, а не для целого музея, записывайте название, оригинальный URL/инвентарный номер, учреждение, дату предмета и дату снимка, географию, социальную среду, материал, назначение, связь с карточками проекта, дату проверки и ограничения использования. Не подменяйте музейную атрибуцию художественным предположением.

Категории: `costumes`, `weapons`, `architecture-exteriors`, `architecture-interiors`, `furniture`, `household-objects`, `industry`, `transport`, `typography`, `daily-life`. Один предмет может иметь несколько категорий. Ссылки и ID связывайте с профильными папками `art/` и `world/`; не копируйте один файл по всем каталогам.

**Права:** доступность изображения онлайн не равна свободной лицензии. Не скачивайте и не коммитьте музейные изображения без отдельной проверки прав на конкретный объект и цифровую репродукцию. Для внешнего изображения с неустановленными правами сохраняйте ссылку и библиографическое описание, не сам файл. См. [правила ресурсов](../../../../studio/ASSET_WORKFLOW.md).

## English

A **link catalog to primary sources**, not a collection of copied museum images. Scope: the Russian Empire and adjacent regions, approximately 1880–1940. Historical sources inform the alternate 1941 setting; they do not automatically define its canon.

### Initial collections

| Collection | URL | Subjects | Note |
| --- | --- | --- | --- |
| Library of Congress — Prokudin-Gorskii | https://www.loc.gov/pictures/collection/prok/ | People, clothing, architecture, industry, transport, rural life | Color photography of the Russian Empire, circa 1905–1915 |
| Library of Congress — Russian prints and photographs | https://guides.loc.gov/russian-collections/special-collections/prints-and-photographs | Photos, posters, postcards, architecture | Guide to several holdings |
| Moscow Kremlin Museums — online collection | https://collectiononline.kreml.ru/en | Arms, dress, textiles, furniture, domestic and decorative objects | Many holdings predate the target period; check individual dates |

### Cataloging rules

For each **selected object**, record its title, original URL/accession number, holding institution, object date versus photograph date, region, social context, materials, function, links to project records, verification date, and usage restrictions. Do not substitute artistic guesses for museum attribution.

Categories: `costumes`, `weapons`, `architecture-exteriors`, `architecture-interiors`, `furniture`, `household-objects`, `industry`, `transport`, `typography`, `daily-life`. An object may have several categories. Cross-reference `art/` and `world/` records by ID instead of duplicating images.

**Rights:** online access is not an open licence. Verify rights for each object and digital reproduction before downloading or committing it. If rights are unresolved, keep a link and bibliographic description only. See the [asset policy](../../../../studio/ASSET_WORKFLOW.md).
