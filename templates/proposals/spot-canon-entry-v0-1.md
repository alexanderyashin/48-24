# Шаблон SPOT: Карточка положения канона

[English](spot-canon-entry-v0-1.en.md) · [Вики](../../studio/navigation/ru/README.md)

**Draft.** Нормативная заготовка для совместной разработки. Авторский статус относится к точной формулировке исходника; перенос и перевод не создают нового согласия соавторов. Перевод ожидает человеческой проверки.

[Источник: SPOT 0.1, §23](../../world/world-bible/drafts/spot-0-1-import.md#section-23) · [Действующие правила канона](../../studio/CANON_POLICY.md).

Исходные статусы: РЕДАКЦИОННОЕ ПРЕДЛОЖЕНИЕ.

**Граница применения.** Ниже сохранены редакционные предложения SPOT. Они не изменяют [рабочий процесс](../../studio/WORKFLOW.md), [метаданные](../../studio/NAMING_AND_METADATA.md) и порядок реального авторского утверждения.

## Карточка положения канона

<!-- SPOT-0.1 section-23 block-2 -->

| Поле | Содержание |
| --- | --- |
| Идентификатор и название | Постоянный номер и короткое предметное название. |
| Формулировка | Одна проверяемая мысль без соединения несовместимых вариантов. |
| Статус | Точная отметка из принятого словаря. |
| Область действия | Эпоха, территория, институт, персонажи или технология. |
| Основание | Основание авторского статуса; отдельно историческая опора и предел её применимости. |
| Зависимости | Какие положения нужны для этой записи и какие зависят от неё. |
| Последствия изменения | Персонажи, сцены, места и изображения, требующие проверки. |
| Вопрос для закрытия | Что конкретно остаётся выбрать или установить. |
