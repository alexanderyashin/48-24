# Сообщество

Фанатские истории, предложения участников и согласованные подборки.

| Область | Содержание |
| --- | --- |
| [Фанатские истории](fan-fiction/README.md) | Ссылки на самостоятельные некоммерческие истории сообщества. |
| [Предложения сообщества](proposals/README.md) | Предложения новых историй, исправлений и расширений мира. |
| [Подборки сообщества](showcase/README.md) | Согласованные подборки и материалы для представления работ участников. |

В каждой области есть `drafts`, `canon` и `archive`. Ветки Git — способ параллельной работы; папки статуса — зрелость материала. Слияние в `main` само по себе не делает материал каноном.

Читайте [рабочий процесс](../studio/WORKFLOW.md) и [правила канона](../studio/CANON_POLICY.md). [Главная](../README.md).
