# Фанатские истории — канон и утверждённые материалы

Здесь `canonical` означает утверждение карточки или ссылки для подборки. Связанная фанработа остаётся неофициальной и не входит в канон мира. Для её официального включения нужны отдельное редакторское решение и необходимые права автора.

Здесь находятся только явно утверждённые материалы. `status: canonical`; для каждого содержательного файла обязательна ссылка decision_ref на реальное решение двух авторов.

Предмет этой папки: ссылки на самостоятельные некоммерческие истории сообщества.

Не исправляйте утверждённый материал напрямую. Подготовьте новую версию в drafts; после решения сохраните прежнюю версию в archive и обновите ссылки.

Для изображений, шрифтов, аудио и других бинарных материалов храните исходник и производные рядом или связывайте их в паспорте ресурса. Доступность файла в интернете не доказывает право на его публикацию здесь.
