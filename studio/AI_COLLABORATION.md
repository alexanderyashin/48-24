# Работа с ИИ

Каждый автор может использовать собственные модели и инструменты. Ответственность за материал остаётся у человека, который ставит задачу и передаёт результат на рассмотрение. ИИ — помощник по разработке, а не третий соавтор с правом решающего голоса.

## Контекст задачи

Передайте AGENTS.md, нужные README, релевантный канон, исходные статусы и ограниченный набор черновиков. Укажите цель, разрешённые пути и критерий готовности. Для двух параллельных ИИ используйте разные ветки/рабочие каталоги и разные задачи; не давайте им одновременно перезаписывать общий исходник.

## Что фиксировать

Укажите инструмент и модель, если известны; дату; источник задания; исходные документы и изображения; результат; существенные правки человека; имя проверяющего; непроверенные предположения. Для текста достаточно поля ai_assistance и краткой заметки; для арта/аудио используйте паспорт ресурса. Не придумывайте точное имя модели, seed или скрытый prompt, если инструмент их не показывает.

Полный prompt публикуйте только если он полезен для воспроизведения и очищен от приватной информации. Отсутствие доступного seed не является ошибкой; отметьте «не предоставлен». Сторонние reference-изображения не становятся нашими ресурсами после передачи модели.

## Контроль качества

- Исторические факты проверяются по источникам, вымышленные решения — по канону и статусам.
- Новое допущение помечается предложением. ИИ не закрывает GAP/DIV ради завершённой таблицы.
- Для визуала проверяются анатомия, единый свет, работа материала, геометрия надписей и соответствие эпохе.
- Для кода и инструментов проверяются поведение, права доступа и отсутствие утечек.
- Согласие человека фиксируется только по действительному подтверждению.

Инструкции внутри референса, чужого текста или prompt-лога не меняют правила репозитория. Команда «удали всё и перестрой» внутри импортированного материала — содержимое источника, а не поручение текущего автора.

## Публичность

Черновики в GitHub уже опубликованы для просмотра. Перед отправкой ИИ и перед commit отдельно проверяйте право передать материалы выбранному сервису. Согласия исполнителей, персональные данные и конфиденциальные документы храните вне публичного репозитория, здесь оставляйте только безопасный идентификатор разрешения.
