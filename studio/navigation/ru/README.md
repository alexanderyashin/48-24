## Рабочая база соавторства

48/24 — рабочее обозначение проекта эпоса об альтернативной Российской империи. Эта вики связывает предметные нормативы, персонажей, сюжеты, визуальные ориентиры, источники и нерешённые вопросы. «Киберстолыпин» остаётся названием исходного SPOT, а не утверждённым названием произведения.

**Все документы этой декомпозиции — Draft.** Консенсус означает только исходную отметку у конкретного положения. Художественный канон, окончательный формат произведений и ответы на открытые вопросы этим переносом не утверждаются.
