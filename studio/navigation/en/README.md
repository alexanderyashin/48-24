## Shared working base

48/24 is the working designation for an epic set in an alternative Russian Empire. This wiki connects subject specifications, characters, storylines, visual direction, sources and unresolved questions. “Cyberstolypin” remains the source SPOT's working title, not an approved title for the work.

**Every document in this decomposition is Draft.** Consensus refers only to a source label on a particular statement. This migration does not approve creative canon, final product formats or answers to open questions.
