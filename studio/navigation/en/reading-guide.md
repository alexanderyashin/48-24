## Find and edit

1. Open a subject wiki page; for a known ID, use repository search or the relevant register.
2. Follow the link to the subject document. The wiki is an index; edit substantive content in the world, narrative, art or production area.
3. Read the exact paragraph's status. A single document may contain source consensus, discussion and gaps.
4. When meaning changes, update both language editions and dependent questions. A new creative decision requires its own approval.
5. Check the individual catalogue entry for every changed or added file and its links from both wikis.

## Reading labels

`Draft` concerns the working edition. `CONSENSUS` means agreement on a particular formulation in the source. `SASHA'S FRAME`, author proposals, joint development and editorial recommendations belong to discussion. `OPEN GAP` means no decision is established. Earlier and cancelled versions appear in variant history.

English translation, cataloguing and merging a branch do not approve canon. All translations from this migration are `draft-unreviewed`: complete translations exist, but technical checks do not substitute for human acceptance.

## Identifiers

| Prefix | Meaning |
| --- | --- |
| CAN | Source statement with its exact authorial status |
| DIV | Divergence requiring consolidation |
| GAP | Missing decision or research |
| CHAR | Character or character function |
| ARC | Storyline, arc or type of story |
| PRI | Proposed decision priority |
| FILE | Individual entry in the file catalogue |

Language documents have different technical IDs and a shared `entity_id`. Subject CAN/CHAR/ARC entities are not duplicated. `.en.md` paths identify English editions; each edition links to its counterpart.

## Outstanding work

Creative questions retain their source statuses. Translations of older organisational files outside SPOT are recorded as legacy language debt. Mandatory catalogue registration is currently a documented rule; there is no new automatic gate against omitted files.
