## Русский

Здесь собраны пошаговые маршруты работы. Выберите инструкцию по своей текущей задаче; прочитывать все руководства перед записью первой идеи не требуется. Нормативные решения находятся в [документах студии](../README.md), а эти инструкции показывают, как применять их на практике. При расхождении сверяйтесь с документом, на который дана ссылка, и отметьте расхождение для исправления.

| Задача | Руководство | Что получится |
| --- | --- | --- |
| Записать идею, написать сюжет, сцену или персонажа | [Тексты и сюжеты](writing.md) | Карточка в подходящей папке с источниками и связями |
| Работать независимо и передать результат соавтору | [Совместная работа](working-together.md) | Понятная задача, отдельная ветка, проверенный PR и следующий шаг |
| Создать арт, музыку, объект, 3D-ресурс или адаптацию | [Ресурсы и продукты](assets-and-products.md) | Материал с назначением, происхождением и честным уровнем готовности |
| Поручить задачу нейросети | [Задания для ИИ](ai-task-briefs.md) | Ограниченная задача с точными путями, контекстом и формой передачи |

Если пока непонятно, к какому направлению относится замысел, начните с [входящих идей](../inbox/README.md). Если нужен уже существующий материал, ищите его в [каталоге](../CONTENT_CATALOG.md), по ID или с помощью [навигатора](../../tools/README.md). Инструкция в README открытой папки объясняет, что хранить именно там.

## English

These guides provide practical task sequences. Choose the one relevant to your current task; you do not need to read every guide before capturing an idea. Binding decisions live in the [studio documents](../README.md). These guides explain their application. If wording differs, consult the linked governing document and flag the inconsistency for correction.

| Task | Guide | Result |
| --- | --- | --- |
| Capture an idea or write a story, scene or character | [Writing and stories](writing.md) | A record in the right folder, with provenance and links |
| Work independently and hand over to a coauthor | [Working together](working-together.md) | A clear task, task branch, checked PR and next step |
| Create art, music, an object, a 3D asset or an adaptation | [Assets and products](assets-and-products.md) | Material with a purpose, provenance and evidenced readiness |
| Delegate a task to an AI assistant | [AI task briefs](ai-task-briefs.md) | A bounded task with exact paths, context and a handoff format |

If an idea's domain is still unclear, start in the [creative inbox](../inbox/README.md). Find existing material through the [catalog](../CONTENT_CATALOG.md), its ID or the [navigator](../../tools/README.md). Each folder's README explains what belongs there.
