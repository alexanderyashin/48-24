# Подготовка выпуска

Каноничность материала, юридическое разрешение и готовность к выпуску — три отдельные проверки. Материал может быть принят художественно и всё ещё не иметь разрешения на коммерческую публикацию использованного шрифта.

## Манифест

Для каждого выпуска создайте карточку в production/releases/drafts по [шаблону адаптации](../templates/adaptation.md) и укажите: продукт и версию, базовый commit, точные пути/ID/версии материалов, внешние мастера и SHA-256, кредиты, языки, необходимые разрешения, канал публикации и человека, который публикует.

## Приёмка

- Текст/сюжет: непротиворечивость, закрытые обязательные вопросы, обозначенные сознательные отклонения.
- Визуал/звук: единый стиль, техническое качество, читаемость, отсутствие дефектов.
- Права: лицензии шрифтов, изображений, музыки, голосов и вкладов; договоры не помещаются в публичный Git.
- Продукт: воспроизводимый экспорт/сборка, читаемые файлы, кредиты, описание и подходящий аудитории доступ.
- Решение: авторы явно согласовали конкретную версию и публикацию. Перенос в canon не публикует ролик и не выпускает книгу автоматически.

После публикации запишите ссылку и фактическую дату в реестр релизов. Для фиксации исходников используйте отдельный tag по продукту, например `youtube-episode-001-v0.1.0`; tag создаётся при реальном выпуске, а не для пустой заготовки.

Проверьте восстановление хотя бы одного внешнего мастер-файла по указанной ссылке и хешу перед первым релизом. GitHub не заменяет резервное копирование внешнего хранилища.
