# Организация: контекст для помощника / Studio assistant context

## Русский

Область: `studio/` и вложенные папки. Это дополнение к [корневому AGENTS.md](../AGENTS.md); его требования и действующие политики сохраняются. Прочитайте [README](README.md), [NAVIGATION](NAVIGATION.md) и README целевой папки.

- Политики, инструкции и реестры имеют одну действующую версию; не создавайте для них конкурирующие `drafts/canon/archive`. Папки входящих, подтверждений, миграций и rollout имеют отдельное назначение.
- Навигатор, карта и каталог помогают найти документы. [structure.json](structure.json) задаёт структуру; профильные политики задают правила. Сводка или сгенерированная ссылка не меняет их и не подтверждает канон.
- В [inbox](inbox/README.md) сохраняйте исходную идею и её происхождение; состояния обработки `captured/triaged/routed/discarded` не заменяют статусы художественного материала.
- В [approvals](approvals/README.md) фиксируются только действительные решения людей с точным предметом и свидетельством. Шаблон, PR или текст помощника не являются таким свидетельством сами по себе.
- Новую памятку связывайте с действующим правилом и обновляйте обе языковые версии. Редактируйте авторский текст README отдельно от автоматически обновляемого блока навигации; команды описаны в [tools](../tools/README.md).

## English

Scope: `studio/` and descendants. This supplements the [root AGENTS.md](../AGENTS.md); its requirements and authoritative policies still apply. Read this area's [README](README.md), [NAVIGATION](NAVIGATION.md) and the target README.

- Policies, instructions and registers have one active version; do not create competing lifecycle copies. Inbox, approvals, migrations and rollout each have their own purpose.
- Navigation, maps and catalogs locate documents. [structure.json](structure.json) defines the structure and the relevant policies define rules. Generated links and summaries neither change policy nor approve canon.
- Preserve original ideas and provenance in the [inbox](inbox/README.md); intake states are distinct from creative status.
- [Approvals](approvals/README.md) record genuine human decisions with precise scope and evidence. A template, PR or assistant text alone is not evidence of approval.
- Link new guides to authoritative policies and maintain both languages. Keep handwritten README prose separate from generated navigation blocks; commands are documented in [tools](../tools/README.md).
