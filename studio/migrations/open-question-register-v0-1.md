# Единый реестр вопросов: запись изменения

**Draft** · [English](open-question-register-v0-1.en.md)

## Задача и исходное состояние

Поручение: собрать недоделанное и неясное в едином предметно организованном реестре, для каждого пункта указать конкретные документы и дополнения после ответа. Работа продолжает SPOT-декомпозицию в ветке `work/sasha/spot-docs-and-bilingual-wiki`, [Draft PR #5](https://github.com/alexanderyashin/48-24/pull/5). Исходная редакция этой задачи — `f33a3c08c88b43b165d57f74e8eaf9f37f5c15e3`.

До изменения CSV содержал 82 исходных GAP/DIV. Поля working_path указывали на карточки вопросов; семь PM-Q имели отдельную текущую таблицу. Не все содержательные остатки и языковые долги были явно зарегистрированы.

## Что изменено

- Один первичный реестр: **183 записей** — 82 исходных GAP/DIV, 7 PM-Q и 94 новых OQ. Исходные ID и содержательные формулировки GAP/DIV сохранены.
- **17 предметных областей** и более узкие темы; **147 open, 35 deferred, 1 resolved**. Условные задачи имеют условия активации.
- **981 связей «вопрос → документ/языковая пара → требуемое действие»** в отдельной нормализованной таблице. Это не второй реестр вопросов.
- Два полных языковых представления, тематические страницы, индекс всех ID и обратный указатель по документам. Старые GAP/DIV-карточки ведут к текущей записи; журнал PM стал указателем.
- Норматив определяет закрытие по критерию и доказательствам, обязательную проверку сопряжённых документов, допустимое «проверено, изменений не требуется» и раздельный учёт Draft, открытости вопроса и исходного согласования.

## Пределы аудита

Дополнительные OQ — редакционная фиксация обнаруженного остатка, не новые авторские решения. Художественные альтернативы не выбраны; исторические и технические гипотезы внешним исследованием не проверялись. Отсутствующие переводы и человеческая приёмка представлены отдельными предметными пакетами с точными файлами. Разработка необязательной арки или адаптации активируется только указанным условием.

Снята лишь устаревшая блокировка PM-Q007, подтверждённая [успешным GitHub Actions run](https://github.com/alexanderyashin/48-24/actions/runs/44629578628) для исходной редакции. В исторические журналы добавлены датированные продолжения; прежние записи о сетевой ошибке не удалены. Игровой конвейер, импортеры и физические испытания остаются самостоятельными вопросами.
