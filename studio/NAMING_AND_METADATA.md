# Имена и метаданные

Новая карточка получает стабильный ID, понятное имя файла и версию. ID описывает объект, версия — его редакцию, путь — рабочий статус. Имя final не является версией.

| Тип | Пример |
| --- | --- |
| Входящий творческий фрагмент | IDEA-0001 |
| Новая карточка мира | WLD-0001 |
| Персонаж | CHAR-0017 |
| Арт-ресурс | ART-0001 |
| Эпизод | EP-0001 |
| Производственная задача | TASK-0001 |
| Решение | DEC-0001 |
| Релиз | REL-0001 |

Исходные CAN/DIV/GAP/CHAR/ARC из SPOT сохраняются, номера не выдаются повторно. Перед присвоением ID выполните поиск по репозиторию. Для независимых предложений допустим временный префикс автора (`ART-SASHA-...`, `ART-IVAN-...`) до объединения в общий реестр; не переименовывайте существующие ссылки без миграции.

Входящие идеи временно хранятся в `studio/inbox/` по [универсальному шаблону](../templates/idea-fragment.md): уникальный `IDEA-...`, оригинал, обе языковые версии, типы, теги, связи и состояние обработки (`captured`, `triaged`, `routed`, `discarded`). Это не художественный канон. После маршрутизации исходная карточка остаётся для прослеживаемости; профильные карточки ссылаются на её ID.

Карточки Markdown в drafts/canon/archive начинаются с плоского front matter. Обязательны `id`, `title`, `status`, `owner`, `updated`, `source`, `ai_assistance`. Рекомендуются `version`, `reviewers`, `canon_refs`, `supersedes`. Дата — YYYY-MM-DD. Списки — JSON-массивы в одной строке, например `reviewers: []`; вложенный YAML не используется.

`owner` — текущий ответственный за работу, не юридический владелец всех прав. `unassigned` допустим для ещё не распределённой стартовой задачи. Авторство и права сохраняются в тексте и паспорте ресурса.

В canon требуется `decision_ref`, ведущий к записи в studio/approvals. В archive требуются `archived_reason` и `superseded_by`. Точное поведение проверки описано в [инструментах](../tools/README.md).

Имена файлов: `station-interior-v0-1.md`, `ART-0001-station-v0-1.png` допустимы, но для новых файлов предпочтителен нижний регистр. Путь короткий, без двоеточий, trailing dots/spaces, Windows reserved names и различий только регистром.
