# Звуковой язык

Музыка, шумы, речь, произношение и звуковые исходники.

| Область | Содержание |
| --- | --- |
| [Музыка](music/README.md) | Темы, мотивы, партитуры, музыкальные брифы и дорожки. |
| [Звуки и атмосферы](sound-design/README.md) | Шумы механизмов, окружения, погоды, Foley и звуковые пространства. |
| [Голоса](voices/README.md) | Кастинг, произношение, голосовые характеры, записи и синтез речи. |

В каждой области есть `drafts`, `canon` и `archive`. Ветки Git — способ параллельной работы; папки статуса — зрелость материала. Слияние в `main` само по себе не делает материал каноном.

Читайте [рабочий процесс](../studio/WORKFLOW.md) и [правила канона](../studio/CANON_POLICY.md). [Главная](../README.md).
