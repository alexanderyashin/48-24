# Словарь рабочих терминов SPOT

[English](spot-working-glossary-v0-1.en.md) · [Вики](../../../studio/navigation/ru/README.md)

**Draft.** Нормативная заготовка для совместной разработки. Авторский статус относится к точной формулировке исходника; перенос и перевод не создают нового согласия соавторов. Перевод ожидает человеческой проверки.

[Источник: SPOT 0.1, §24](spot-0-1-import.md#section-24) · [Действующие правила канона](../../../studio/CANON_POLICY.md).

Словарь сохраняет формулировки исходного снимка. «Киберстолыпин» — прежнее рабочее название; сейчас проект называется 48/24. Широкое употребление слова «канон» в исходнике не заменяет действующее правило о точном утверждении обоими соавторами.

<!-- SPOT-0.1 section-24 block-0 -->

Словарь описывает проектные термины. Язык персонажей, названия учреждений, официальные титулы и политические самоназвания требуют отдельной разработки и утверждения.

<!-- SPOT-0.1 section-24 block-1 -->

| Термин | Рабочее значение |
| --- | --- |
| Альтернативная история | Развитие реального исторического мира после выбранной точки расхождения. |
| Арка | Изменение персонажа или системы под действием событий и выборов. |
| Библия мира | Свод правил, связей и материалов для согласованности произведений. |
| Горнозаводской округ | Производственная и социальная территория вокруг взаимосвязанных предприятий; параметры альтернативной версии требуют разработки. |
| Железный Канцлер | Устойчивое обозначение Столыпина в авторском замысле; формальный титул и юридический статус уточняются. |
| Канон | Положения мира с определённым авторским статусом; в узком смысле согласованная действующая основа. |
| Киберстолыпин | Рабочее название проекта; публичное название ещё не утверждено. |
| Контрэлита | Группа с ресурсами и связями, способная оспаривать существующее распределение власти; не моральная оценка. |
| Логлайн | Краткая формула героя, конфликта и значимого исхода или риска. |
| Механизация | Общий термин нескольких пока не сведённых технических вариантов преобразования правителя. |
| Паровой Государь | Ранний образ правителя; соответствие конкретному персонажу является развилкой. |
| Пустоши | Рабочее название периферийных пространств и анклавов; природная среда, границы и употребление слова внутри мира не утверждены. |
| Союз Социалистических Корпораций | Предложенная Сашей форма последующего производственного объединения; конституция и точное название открыты. |
| Сквозной герой | Персонаж, связывающий длительную историческую дугу; не обязательно единственный носитель точки зрения. |
| Фракция | Группа с общими интересами и волей к действию; не обязательно партия. |
| Флешбэк | Показ прошлого вне хронологического порядка; может быть субъективным. |
| Эпоха | Период с определённым устройством общества и его противоречиями. |
| SPOT | Единый источник текущих положений, решений, вариантов и пробелов. |
