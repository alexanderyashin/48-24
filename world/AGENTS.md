# Мир: контекст для помощника / World assistant context

## Русский

Область: `world/` и вложенные папки. Это дополнение к [корневому AGENTS.md](../AGENTS.md); его требования и действующие политики сохраняются. Начните с [README](README.md), README целевой области и [навигатора задач](../studio/NAVIGATION.md).

- Факты и правила общего мира размещайте в `drafts` подходящей области: география, институты, общество, экономика, технологии и другие разделы README. Для материала без понятной категории используйте [входящие идеи](../studio/inbox/README.md).
- Выберите [положение мира](../templates/world-entry.md), [локацию](../templates/location.md), [фракцию](../templates/faction.md), [технологию](../templates/technology.md) или [объект OBJ](../templates/world-object.md). Проверьте ID, связанные канонические записи, черновики и открытые вопросы до создания карточки.
- Реальный исторический источник относится к `research/`, сюжет — к `narrative/`, визуальная реализация — к `art/`. Связывайте их по ID и относительным ссылкам. Для материальных объектов прочитайте [OBJECT_STANDARD](../studio/OBJECT_STANDARD.md).
- Сохраняйте авторские статусы SPOT, неизвестные параметры и развилки. Импорт источника не переписывается ради исправления отдельной рабочей карточки. Новый черновик, перевод и принятие канона — разные действия по [CANON_POLICY](../studio/CANON_POLICY.md).

## English

Scope: `world/` and descendants. This supplements the [root AGENTS.md](../AGENTS.md); its requirements and authoritative policies still apply. Start with this area's [README](README.md), the target README and the [task navigator](../studio/NAVIGATION.md).

- Put shared-world facts and rules in the relevant area's `drafts`; use the [inbox](../studio/inbox/README.md) when classification is unclear.
- Choose the linked world-entry, location, faction, technology or OBJ template. Check existing IDs, canon, drafts and open questions before creating a record.
- Historical evidence belongs in `research/`, plot in `narrative/`, visual realizations in `art/`. Cross-link IDs and paths rather than copying records. Read [OBJECT_STANDARD](../studio/OBJECT_STANDARD.md) for material objects.
- Preserve SPOT authorial statuses, unknowns and alternatives. Do not rewrite the source import to change one working record. Drafting, translation and canon approval remain distinct under [CANON_POLICY](../studio/CANON_POLICY.md).
