# Мир

Общие факты и правила вселенной, на которые опираются все произведения.

| Область | Содержание |
| --- | --- |
| [Библия мира](world-bible/README.md) | Общий замысел, тематическое ядро, правила реальности, границы фантастического допущения и взаимосвязи мира. |
| [Хронология](chronology/README.md) | Даты, эпохи, последовательности событий, возраст персонажей и альтернативные исторические развилки. |
| [География](geography/README.md) | Территории, города, маршруты, климат, логистика и географические ограничения. |
| [Государство и институты](institutions/README.md) | Устройство власти, право, армия, службы, церковь и процедуры принятия решений. |
| [Фракции](factions/README.md) | Группы интересов, организации, цели, ресурсы, конфликты и отношения. |
| [Общество и повседневность](society/README.md) | Культура, сословия, религия, языки, образование, быт и социальная мобильность. |
| [Экономика](economy/README.md) | Производство, собственность, труд, деньги, снабжение, торговля и инфраструктурные зависимости. |
| [Технологии](technology/README.md) | Энергия, механизация, связь, транспорт, вооружение и технические ограничения. |

В каждой области есть `drafts`, `canon` и `archive`. Ветки Git — способ параллельной работы; папки статуса — зрелость материала. Слияние в `main` само по себе не делает материал каноном.

Читайте [рабочий процесс](../studio/WORKFLOW.md) и [правила канона](../studio/CANON_POLICY.md). [Главная](../README.md).
