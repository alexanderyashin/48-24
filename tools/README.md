# Инструменты репозитория

Здесь находятся небольшие проверяемые средства сопровождения проекта. Они проверяют организационные правила и не меняют художественные материалы. Движок компьютерной игры и производственные программы относятся к своим продуктовым направлениям.

- [validate_repo.py](validate_repo.py) проверяет структуру, метаданные, ссылки, архив и записи о правах.
- [tests](tests/README.md) содержит проверки того, что предохранители действительно находят ошибки.
- [Описание проверок](../studio/repository-checks.md) объясняет правила, форматы и ограничения.

Из корня репозитория:

```bash
python3 tools/validate_repo.py --root .
python3 -m unittest discover -s tools/tests -p 'test_*.py' -v
```

В PowerShell используйте `python` вместо `python3`, если именно так называется установленный интерпретатор. Дополнительные библиотеки не требуются; поддерживается Python 3.10 и новее.

Перед проверкой удаления или переноса файлов выполните `git add -A`, затем сравните с полным SHA исходного коммита через `--base`. В локальной рабочей копии проверяются отслеживаемые и новые неигнорируемые файлы; в чистой CI-копии — содержимое коммита.

Менять проверяющий код, workflows или контракт структуры следует отдельным PR с объяснением цели и сохранением защитных свойств. ИИ-помощник не вправе отключать проверку ради зелёного результата.
